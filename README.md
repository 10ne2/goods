# 차곡
묶음별 구매·판매를 한 장의 스프레드시트에서 관리하는 개인용 웹 가계부.

## 개발
Node.js 22.12 이상(검증: 24.19), npm을 사용합니다.

```sh
npm ci --cache /tmp/goods-npm-cache --no-audit --no-fund
npm run dev -- --port 5173
```

```sh
npm test
npm run build
```

## 장부 사용
첫 화면의 빈 칸에서 바로 입력하며, 버튼이나 팝업으로 등록하지 않습니다.

- 주황색 구매 영역: 묶음 이름, 상품명·가격·구매상황, 묶음 배송비, 구매 총합.
- 파란색 판매 영역: 구매 행과 별도로 상품명·판매가·판매상황을 입력. 한 묶음에서 구매 수량과 판매 행 수가 달라도 됩니다.
- 배송비는 묶음당 한 번 합산합니다. 기타 비용은 배송비 칸의 펼침 항목에서 입력합니다. 판매 배송비·수수료는 각 판매가 칸의 `판매 비용`에서 입력합니다.
- 마지막 상품 행에 입력하면 다음 빈 행이 생깁니다. 마지막 묶음에 입력하면 다음 빈 묶음이 생깁니다.
- Tab / Shift+Tab으로 옆 입력 칸, Enter / Shift+Enter와 위아래 방향키로 같은 종류·열의 다음 행에 이동합니다.
- 약 350ms 동안 입력이 없거나 다른 칸으로 이동하면 자동 저장합니다. 미완성 이름·가격도 작성 중 상태 그대로 보존합니다. 음수·소수·범위 초과 금액이 있으면 전체 저장을 대기하고 이전 저장본을 유지합니다. 화면의 저장 상태를 확인하세요.
- 묶음·상품 검색, 상품 행 삭제, 묶음 삭제, CSV 내보내기를 지원합니다.

## 계산 기준
- 구매 총합 = 구매 가격 합계 + 묶음 배송비 + 기타 비용.
- 현재총합 = `판매완료` 상태의 판매가 합계.
- 예상총합 = `판매중`·`예약중`·`판매완료`의 판매가 합계.
- 현재 차액 = 구매 총합 − 현재총합 + 완료 판매의 배송비·수수료.
- 확정 차액 = 구매 총합 − 예상총합 + 전체 판매의 배송비·수수료.

차액은 아직 회수하지 못한 구매 비용입니다. 음수는 이익입니다. `확정 차액`이라는 제목은 예시 이미지에 맞췄으며, 판매중 가격을 포함하므로 판매가 완료되기 전에는 예상값입니다. 예시: 구매 162,200원, 현재 판매 30,000원, 예상 판매 73,000원 → 현재 차액 132,200원, 확정 차액 89,200원.

## 데이터
`goods-ledger-groups-v2`라는 브라우저 localStorage 키를 사용합니다. 기존 `goods-ledger-v1` 기록은 개별 묶음으로 자동 변환하며 기존 원본 키는 수정하지 않습니다. 기존 구매·판매 날짜 및 모든 비용도 보존하고 CSV에 날짜를 포함합니다. 새 묶음 양식에는 날짜 입력 열이 없습니다.

계정이나 서버 동기화가 없으며 브라우저 데이터 삭제 시 기록도 사라집니다. 중요한 기록은 CSV로 백업하세요. CSV 가져오기는 아직 지원하지 않습니다. 잘못된 저장 데이터를 발견하면 자동 저장을 중지하여 덮어쓰지 않습니다.
