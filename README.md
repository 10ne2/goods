# 모니굿즈
묶음별 구매·판매를 한 장의 스프레드시트에서 관리하는 개인용 웹 가계부.

## 개발
Node.js 22.12 이상(검증: 24.19), npm을 사용합니다.

```sh
npm ci --cache /tmp/goods-npm-cache --no-audit --no-fund
npm run dev -- --port 5173
```

```sh
npm test
npm run build
```

## 장부 사용
기본 화면에서 구매·판매 한 행씩 있는 묶음으로 시작합니다. 구매 내역과 판매 내역의 맨 위 제목에만 색을 사용하며, 표 본문은 흰색입니다.

- `묶음 추가`로 구매·판매 한 행씩 있는 새 묶음을 만듭니다.
- 각 구매·판매 영역의 마지막 행 아래에 있는 전체 5열 너비 `＋`로 필요한 쪽의 행만 늘립니다. 자동으로 행·묶음을 추가하지 않습니다.
- 구매 쪽 이름 열은 제거했습니다. 묶음 번호·이름은 표에 표시하지 않고 묶음 사이에 표 선과 같은 색의 3px 선으로 구분합니다. 확정 차액 오른쪽 `×`로 해당 묶음 전체를 삭제할 수 있습니다. 기존 이름 데이터는 보존합니다.
- 각 칸을 바로 편집하고 자동 저장합니다. 입력 포커스에 배경이나 테두리를 표시하지 않으며 행 높이는 24px입니다.
- 배송비는 묶음당 한 번 합산합니다. 추가비용 입력 영역은 제거했습니다. 이전에 저장된 기타 비용·판매 배송비는 데이터와 계산에 보존합니다. 수수료는 계산하지 않습니다.
- Tab / Shift+Tab으로 옆 입력 칸, Enter / Shift+Enter와 위아래 방향키로 같은 종류·열의 다음 행에 이동합니다.
- 약 350ms 동안 입력이 없거나 다른 칸으로 이동하면 자동 저장합니다. 추가한 빈 묶음과 빈 행도 보존합니다. 음수·소수·범위 초과 금액이 있으면 전체 저장을 대기하고 이전 저장본을 유지합니다.
- 묶음·상품 검색, 상품 행 삭제, CSV 내보내기를 지원합니다.

표 제목은 **묶음 테이블**이며 개별 표와 구분합니다. 구매·판매 범례, 단위 표시, 정상 자동 저장 안내는 표시하지 않습니다. 저장 실패와 금액 오류만 안내합니다. 좁은 화면에서 스크롤바를 숨기고 표 위의 마우스 휠을 좌우 이동으로 사용합니다. 좌우 끝에서는 페이지 세로 스크롤로 이어집니다. 터치 스와이프·트랙패드 좌우 이동도 가능합니다.

금액은 입력 중과 재접속 시 모두 `12,345`처럼 표시합니다. 숫자 중간 편집 시 커서 위치를 유지하며 저장·계산·CSV에는 쉼표 없는 원래 숫자를 사용합니다. 개별 표에도 동일한 금액 표시를 적용합니다.

구매상황은 묶음당 하나의 셀로 데이터 행만큼 병합합니다. 변경 시 묶음 내 구매 행의 저장 상태도 함께 갱신합니다. 기존 상태는 첫 구매 행에서 가져오며 새 묶음은 `주문완료`입니다. 판매 합계 셀도 해당 판매 표의 데이터 행에만 병합하며, 구매·판매의 행 수가 달라도 `＋` 행을 포함하지 않습니다.

## 개별 구매·판매
묶음 장부 아래에 개별 구매 표와 개별 판매 표를 좌우 한 줄로 제공합니다. 작은 화면에서도 두 표를 세로로 쌓지 않고 가로 스크롤로 봅니다.

- 구매만 하거나 판매만 하는 기록을 묶음 없이 입력합니다. 각 표는 한 행으로 시작하며 표 밖 제목 옆의 `＋`로 해당 표의 행만 추가합니다.
- 개별 구매 총비용 = 가격 + 배송비.
- 개별 판매 정산액 = 판매가 − 내가 부담한 배송비. 판매완료 정산액과 판매중·예약중을 포함한 예상 정산액을 별도로 표시합니다.
- 상단 `묶음 장부 요약`은 묶음 내역만 계산하며, 개별 표는 자기 합계를 따로 표시합니다. 개별 판매만으로는 구매 원가를 알 수 없어 손익으로 표시하지 않습니다.
- 인라인 입력·자동 저장·행 삭제·키보드 이동을 지원합니다. 두 표의 행 수와 저장 데이터는 묶음 장부와 독립적입니다. 별도 삭제 열은 없으며 상품명에 마우스를 올리거나 키보드로 포커스하면 `×`가 표시됩니다.
- CSV 내보내기에는 묶음 기록과 `개별 구매`·`개별 판매` 기록을 함께 포함합니다. 검색 창은 기존 묶음 장부를 검색합니다.

구매 기본 상태는 `주문완료`, 판매 기본 상태는 `판매전`입니다. 묶음과 개별 표 모두 동일하며 기존 기록의 상태는 유지합니다. 판매 상태는 `판매전`·`판매전`·`판매중`·`예약중`·`판매완료`를 지원합니다.

## 계산 기준
- 구매 총합 = 구매 가격 합계 + 묶음 배송비 + 기타 비용.
- 현재총합 = `판매완료` 상태의 판매가 합계.
- 예상총합 = `판매전`·`판매중`·`예약중`·`판매완료`의 판매가 합계.
- 현재 차액 = 구매 총합 − 현재총합 + 완료 판매의 배송비.
- 확정 차액 = 구매 총합 − 예상총합 + 전체 판매의 배송비.

차액은 아직 회수하지 못한 구매 비용입니다. 음수는 이익입니다. `확정 차액`이라는 제목은 예시 이미지에 맞췄으며, 판매중 가격을 포함하므로 판매가 완료되기 전에는 예상값입니다. 예시: 구매 162,200원, 현재 판매 30,000원, 예상 판매 73,000원 → 현재 차액 132,200원, 확정 차액 89,200원.

## 데이터
묶음은 `goods-ledger-groups-v2`, 개별 구매·판매는 `goods-ledger-independent-v1`이라는 브라우저 localStorage 키를 사용합니다. 기존 `goods-ledger-v1` 기록은 개별 묶음으로 자동 변환하며 기존 원본 키는 수정하지 않습니다. 기존 구매·판매 날짜와 배송비·기타 비용을 보존하고 CSV에 날짜를 포함합니다. 이전 수수료 값은 새 계산과 CSV에서 제외합니다. 이전 자동 생성 빈 행은 최초 변환 시 정리하며, 이후 직접 추가한 빈 행은 유지합니다. 새 묶음 양식에는 날짜 입력 열이 없습니다.

계정이나 서버 동기화가 없으며 브라우저 데이터 삭제 시 기록도 사라집니다. 중요한 기록은 CSV로 백업하세요. CSV 가져오기는 아직 지원하지 않습니다. 잘못된 저장 데이터를 발견하면 자동 저장을 중지하여 덮어쓰지 않습니다.

## GitHub Pages
`.github/workflows/pages.yml`이 main 브랜치의 변경을 테스트하고 `/goods/` 경로로 빌드하여 배포합니다. Settings → Pages → Source는 **GitHub Actions**를 사용합니다. 주소: https://10ne2.github.io/goods/

## 표 스타일
묶음·개별 표는 같은 색의 1px 경계선을 사용하고 묶음 경계만 3px로 표시합니다. 경계선은 서로 겹쳐 두꺼워지지 않도록 처리합니다. 기본 글자색은 #777, 상품명 입력 안내는 #ddd이며 금액 입력과 합계는 오른쪽 정렬합니다. 입력 오류는 빨간 글자로 구분합니다. 빈 행·빈 묶음 삭제는 확인창을 생략하고, 상품명이나 금액이 있는 기록 삭제는 확인합니다.

## 상태 배경색 및 표 정렬
구매 배송중은 연한 주황색, 수령완료는 진한 주황색을 표시합니다. 판매중은 연한 파란색, 배송중은 중간 파란색, 판매완료는 진한 파란색을 표시합니다. 주문완료·판매전·예약중은 흰색입니다. 구매는 묶음 상태 전체에, 판매는 해당 행에 적용하며 병합 판매 합계 칸도 행별로 같은 색 띠를 표시합니다. 개별 표도 같은 상태색을 적용합니다.

묶음 장부는 하나의 공통 colgroup을 사용하는 단일 표로 그려, 헤더·데이터·추가 버튼·묶음 사이 열 경계가 일치합니다.

개별 판매 표의 배송비 입력 열은 삭제했습니다. 구매 배송비 입력은 유지하며, 기존에 저장된 개별 판매 배송비는 데이터·CSV와 정산 계산에 보존합니다. 새 개별 판매는 배송비 0으로 계산합니다.

## 월별 장부
처음에는 9월로 표시합니다. 월 정보가 없는 기존 묶음·개별 기록도 모두 9월로 보존합니다. 상단 월 선택으로 1~12월을 전환하며 마지막 선택한 월을 기억합니다. 해당 월의 묶음·개별 기록과 합계만 표시하고 새 기록은 선택한 월에 생성합니다.

묶음 표의 확정 차액 오른쪽 `월`을 변경하면 묶음 전체가 해당 월로 이동합니다. 다른 월로 이동한 묶음은 현재 화면에서 사라지며, 상단에서 이동한 월을 선택하면 확인할 수 있습니다. 저장이 실패하거나 금액 오류가 있으면 월 이동·전환을 완료하지 않아 기록이 유실되지 않도록 합니다. 개별 기록은 생성한 월을 따르며 별도 월 이동 입력은 없습니다.

CSV는 백업을 위해 선택한 월뿐 아니라 모든 월의 기록을 내보내며 마지막 열에 월을 포함합니다. 현재 월 구분은 연도 없는 1~12월입니다.
