# 차곡
구매 상품의 원가와 배송비, 판매가와 수수료를 기록하는 개인용 웹 가계부.

## 개발
Node.js 22.12 이상(현재 검증: 24.19), npm을 사용합니다.

```sh
npm ci
npm run dev -- --port 5173
```

```sh
npm test
npm run build
```

구매 기록 추가·수정·삭제, 판매 등록·수정·취소, 검색과 상태 필터, CSV 내보내기를 지원합니다. 손익은 판매가에서 구매가·구매 배송비·기타 비용·판매 배송비·수수료를 차감합니다. 판매하지 않은 상품은 판매 손익에 포함하지 않습니다.

데이터는 현재 브라우저의 localStorage에 저장됩니다. 계정·서버 동기화는 없으며 브라우저 데이터 삭제 시 기록도 사라집니다. 중요한 기록은 CSV로 백업하세요. CSV 가져오기는 아직 지원하지 않습니다.

## GitHub Pages 배포
`.github/workflows/pages.yml`이 main 브랜치의 변경을 테스트하고 `/goods/` 경로로 빌드한 뒤 배포합니다. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택해야 합니다. 예상 주소는 https://10ne2.github.io/goods/ 입니다. GitHub Pages 활성화 및 성공한 배포가 있어야 이 주소로 접속할 수 있습니다.

## 스프레드시트 입력
처음부터 빈 행 10개가 표시됩니다. 상품명·구매일·구매가·배송비·판매가 등 각 열의 칸을 직접 편집합니다. 추가·수정·저장 버튼은 없습니다.

- 입력을 멈춘 뒤 약 350ms 또는 다른 칸으로 이동할 때 브라우저에 자동 저장합니다.
- 상품명을 입력하면 구매일이 오늘로 채워집니다. 상품명·구매일·구매가는 필수이며, 배송비·기타 비용은 빈칸이면 0원입니다.
- 판매가 입력 시 판매일이 오늘로 채워지고 판매 완료로 계산합니다. 판매가를 비우면 판매를 취소합니다. 0원 판매도 기록할 수 있습니다.
- Tab / Shift+Tab으로 옆 칸, Enter / Shift+Enter 또는 위아래 방향키로 같은 열의 다른 행에 이동합니다.
- 마지막 빈 행에 입력하면 다음 빈 행이 자동으로 생깁니다. 작은 화면은 표 안에서 가로 스크롤합니다.
- 기존 구매·판매 기록은 같은 localStorage 키로 유지됩니다. 입력이 미완성이거나 금액이 유효하지 않은 행은 저장하지 않으며 기존 저장 기록을 보존합니다. 상태 문구에서 저장 결과를 확인하세요.
- CSV는 저장된 기록을 내보냅니다. 브라우저 저장 실패 또는 미완성 행은 새로고침 전 확인해야 합니다.
